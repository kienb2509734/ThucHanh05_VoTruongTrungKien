# Bài Thực Hành 05 - Quản Lý Phiên Bản Bằng Git/GitHub

## 1. Danh sách File Thực Hành
- `NhiemVu1_1_1_2.pdf`: File PDF cho nhiệm vụ 1.1 và 1.2.
- `NhiemVu2_1.png`: File hình ảnh PNG cho nhiệm vụ 2.1.
- `NhiemVu2_2.mp4` (hoặc `Link_Google_Drive.txt`): File video / đường dẫn video cho nhiệm vụ 2.2.
- `NhiemVu3_1.html`: File mã nguồn HTML cho nhiệm vụ 3.1.

## 2. Trích Dẫn Nguồn AI
Trong quá trình hoàn thành bài thực hành, các công cụ AI sau đây đã được sử dụng hỗ trợ:
- **Canva AI**: Hỗ trợ thiết kế và tạo nội dung hình ảnh/đồ họa.
- **Microsoft Copilot**: Hỗ trợ gợi ý mã nguồn, tối ưu hóa câu chữ và xử lý văn bản.

## 3. Giấy Phép Sử Dụng
Dự án này được chia sẻ dưới giấy phép **Creative Commons Attribution (CC BY)**. Bạn có thể tự do chia sẻ và chỉnh sửa nội dung với điều kiện trích dẫn nguồn đầy đủ.
